KGM Office Vote scroll story

Open index.html in Chrome. The office illustration at the start is above the moving SUV, which emerges after the first scroll. All other illustrated story scenes and the Microsoft Forms embed placeholder remain in place.

To add the ballot: in index.html find MICROSOFT_FORMS_EMBED_URL and paste the URL from the iframe src provided by Microsoft Forms. Configure organisation-only, one response per person, record name off.

For GitHub Pages, upload index.html and the assets directory together. The published site itself will be public; do not include confidential company content.
